3208 買い物リスト PWA版

ファイル:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

重要:
PWAは file:// で直接開くだけではインストールできません。
HTTPS対応の公開先へ、このフォルダ内の全ファイルを同じ階層でアップロードしてください。

公開後:
Android Chrome:
1. 公開URLを開く
2. 画面上の「ホーム画面に追加」またはブラウザメニューからインストール

iPhone Safari:
1. 公開URLをSafariで開く
2. 共有
3. ホーム画面に追加

オフライン時:
画面本体は起動できますが、Supabaseへの読み書きには通信が必要です。
